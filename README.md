# Rُuh (رُوح) 🌙

> **Feed your soul, distraction-free.**

Rُuh is a next-generation, premium Islamic web platform designed to provide an immersive and distraction-free spiritual experience. Moving away from traditional text-heavy designs, Rُuh integrates modern UX principles and seamless audio-text synchronization to create a peaceful digital sanctuary.

### 🚀 Tech Stack

- **Frontend:** Next.js (App Router), React, Tailwind CSS
- **Animations:** GSAP, Framer Motion
- **Backend & Database:** Next.js API Routes, MongoDB, Mongoose
- **Authentication:** NextAuth.js (Auth.js)
- **Data Sources:** Quran.com API v4, Aladhan API

### ✨ Key Features

- **Distraction-Free Focus Mode:** Clean, minimalist reading environment.
- **Spiritual Dashboard:** Habit tracking, daily reading streaks, and customized bookmarks.
- **Glassmorphism UI:** Deep Dark Mode ("Deep Sanctuary") with frosted glass components.
